# Как это работает

Что делает скрипт

`speed_test.py` измеряет скорость скачивания ресурса по его URL.

1. **Приём аргументов.** Скрипт принимает URL (обязательный) и необязательный
   флаг `-n/--count`: количество запросов (по умолчанию 10).
2. **Подготовка запроса.** Формируется `urllib.request.Request` с заголовком
   `User-Agent`, чтобы серверы не отклоняли запросы от скрипта.
3. **Последовательные запросы.** В цикле выполняется `count` итераций. На каждой:
   - засекается время через `time.perf_counter()` (высокоточный таймер);
   - выполняется `urllib.request.urlopen(request)`, ответ полностью читается
     методом `.read()` (это гарантирует, что дождались полного ответа);
   - вычисляется время запроса и размер полученных данных (`len(data)`).
   - результаты накапливаются: список времён и суммарный объём байт.
4. **Обработка ошибок.** Если любой запрос завершается исключением (сеть, HTTP-ошибка,
   таймаут), скрипт печатает в stderr подробное описание: тип ошибки, код статуса
   и тело ответа для HTTP-ошибок, причину для сетевых ошибок, время до ошибки и
   число успешных запросов до неё. Завершается с кодом 1. Частичные результаты
   не выводятся. Таймаут одного запроса задаётся флагом `--timeout` (по умолчанию
   30 с).
5. **Подсчёт метрик.**
   - среднее время запроса = сумма времён / количество запросов;
   - общий объём = сумма размеров всех ответов;
   - общее время = сумма времён всех запросов;
   - скорость = (общий объём × 8 бит) / общее время → Мбит/с.
6. **Вывод.** Печатаются построчные результаты каждого запроса и итоговая
   сводка: среднее время, общий объём, общее время, скорость.
7. **HTML-отчёт.** `HtmlReportGenerator.generate` строит HTML-страницу с таблицей
   по каждому запросу и итоговой сводкой, сохраняет её в файл (по умолчанию
   `report.html`).
8. **Веб-сервер.** Если не передан `--no-serve`, `ReportServer` запускает
   локальный HTTP-сервер на указанном порту (по умолчанию 8000) и отдаёт
   сгенерированный HTML-отчёт, пока пользователь не нажмёт Ctrl+C. Адрес
   переиспользуется (SO_REUSEADDR), а при занятом порте печатается понятная
   ошибка с предложением выбрать другой порт.

Почему последовательно

Запросы идут один за другим, чтобы измерить реальное время полного ответа
для каждого запроса без конкуренции за соединение или канал.
single-stream скачивания получается стабильнее.

Зависимости

Используется только стандартная библиотека Python (`argparse`, `sys`,
`time`, `urllib.request`), поэтому установка пакетов не требуется.
