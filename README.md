# download-speed-test

Консольный скрипт на Python, который измеряет скорость скачивания по заданному URL.
Делает 10 последовательных запросов, дожидаясь полного ответа на каждый,
считает среднее время запроса и общий объём скачанных данных, печатает скорость.

## Требования

- Python 3.7+
- Внешние зависимости не нужны, используется только стандартная библиотека.

## Запуск

```bash
python3 speed_test.py <URL>
```

Пример:

```bash
python3 speed_test.py https://example.com/large-image.jpg
```

Дополнительно можно указать количество запросов (по умолчанию 10):

```bash
python3 speed_test.py https://example.com/large-image.jpg -n 5
```

Сделать скрипт исполняемым (необязательно):

```bash
chmod +x speed_test.py
./speed_test.py https://example.com/large-image.jpg
```

## Единицы измерения

- Время запроса в секундах.
- Объём данных в байтах с автоматическим переводом в KB, MB, GB (основание 1024).
- Скорость скачивания в мегабитах в секунду (Мбит/с, 1 Мбит = 1 000 000 бит).
  В скобках дополнительно выводится скорость в мебибайтах в секунду (MB/s,
  1 MB = 1024×1024 байт).

## Пример вывода

```
URL: https://example.com/large-image.jpg
Запросов: 10
----------------------------------------
[1/10]      2.34 MB |  0.412 с |   46.80 Мбит/с
...
----------------------------------------
Среднее время запроса: 0.405 с
Общий объём данных:    23.40 MB (24536000 байт)
Общее время:           4.050 с
Скорость скачивания:   48.47 Мбит/с (5.78 MB/s)
```

## Классы и функции

Скрипт состоит из следующих частей.

**RequestResult** (dataclass). Хранит результат одного запроса: `size` (размер
ответа в байтах) и `elapsed` (время запроса в секундах).

**ByteFormatter**. Отвечает за форматирование объёма данных. Статический метод
`format_bytes(n)` переводит число байтов в строку с подходящей единицей
(B, KB, MB, GB).

**DownloadSpeedTester**. Выполняет серию запросов и считает метрики.
- `__init__(url, count=10)` сохраняет адрес, количество запросов и готовит объект
  запроса с заголовком User-Agent.
- `measure_one()` делает один запрос, читает ответ полностью, возвращает
  `RequestResult`.
- `run()` выполняет все запросы последовательно и сохраняет результаты в
  `self.results`.
- Свойства `total_bytes`, `total_time`, `average_time`, `speed_mbps`,
  `speed_mbs` возвращают суммарный объём, суммарное время, среднее время,
  скорость в Мбит/с и скорость в MB/s.

**ConsoleReporter**. Печатает результаты в консоль. Принимает экземпляр
`DownloadSpeedTester`.
- `print_header()` выводит адрес и количество запросов.
- `print_result(index, result)` выводит строку по одному запросу.
- `print_summary()` выводит итоговую сводку.

**parse_args()**. Разбирает аргументы командной строки (URL и необязательный
`-n/--count`).

**main()**. Создаёт тестер и репортёр, запускает запросы с обработкой ошибок,
печатает результаты.
