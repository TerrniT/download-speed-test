# download-speed-test

Консольный скрипт на Python, который измеряет скорость скачивания по заданному URL.
Делает 10 последовательных запросов, дожидаясь полного ответа на каждый,
считает среднее время запроса и общий объём скачанных данных, печатает скорость.

## Требования

- Python 3.7+
- Внешние зависимости не нужны (используется только стандартная библиотека).

## Запуск

```bash
python3 speed_test.py <URL>
```

Пример:

```bash
python3 speed_test.py https://example.com/large-image.jpg
```

Дополнительно можно указать количество запросов (по умолчанию 10):

```bash
python3 speed_test.py https://example.com/large-image.jpg -n 5
```

Сделать скрипт исполняемым (опционально):

```bash
chmod +x speed_test.py
./speed_test.py https://example.com/large-image.jpg
```

## Единицы измерения

- Время запроса — секунды (с).
- Объём данных — байты с автоматическим переводом в KB / MB / GB (основание 1024).
- Скорость скачивания — мегабиты в секунду (Мбит/с, 1 Мбит = 1 000 000 бит).
  В скобках дополнительно выводится скорость в мебибайтах в секунду (MB/s, 1 MB = 1024×1024 байт).

## Пример вывода

```
URL: https://example.com/large-image.jpg
Запросов: 10
----------------------------------------
[1/10]      2.34 MB |  0.412 с |   46.80 Мбит/с
...
----------------------------------------
Среднее время запроса: 0.405 с
Общий объём данных:    23.40 MB (24536000 байт)
Общее время:           4.050 с
Скорость скачивания:   48.47 Мбит/с (5.78 MB/s)
```
